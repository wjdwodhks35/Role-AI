# ChatGPT 자동 허용 모드

학습 데이터의 설정 화면에서 켤 수 있는 소유자 전용 정책입니다. 기본은 꺼짐입니다. 자동 수집 경로로 보관한 최대 30행의 SFT 데이터에만 적용하며 파일/메일/명령/브라우저 권한과 모델 배포를 위임하지 않습니다.

켜려면 OpenAI API 키·모델·단가·요청/일일 예산, 로컬 기반 모델 경로·revision이 준비돼야 합니다. 설정 화면에서 해당 예산과 외부 전송·반복 호출 비용, 데이터/개인정보/모델 이용 조건의 위임 범위를 확인합니다. ChatGPT 웹 구독을 API 크레딧으로 사용하거나 쿠키를 추출하지 않습니다. 기존 공식 Responses API만 사용합니다.

자동 수집의 로컬 Teacher/Reviewer 검수가 통과하면 ChatGPT가 모든 선택된 학습/평가 샘플과 출처·역할·제한된 학습 계획을 검토합니다. upstream 데이터셋 전체를 검토하는 것은 아닙니다. JSON verdict=pass이고 risks가 비어 있을 때만 데이터 해시·검수·모델 지문·계획에 묶인 승인 해시를 만듭니다. 이때 이전 로컬 오케스트레이터 검수를 GPT 결과로 교체합니다. 거절·위험 표시·오류·예산 부족이면 승인하지 않습니다. 이미 수집한 reviewed 데이터는 정책에 따라 심사 버튼으로 평가할 수 있습니다.

GPT는 법적 권리·개인정보 안전·학습 품질을 보장하지 않습니다. 자동 모드는 사용자가 확인한 범위에 대해 승인 판단을 위임하는 설정입니다. 최종 학습 여부는 기존 GPU 학습 활성화 설정과 작업 등록/Worker가 별도로 결정합니다. 자동 큐 등록과 자동 모델 배포는 하지 않습니다.

정책 변경/끄기는 아직 시작하지 않은 해당 자동 승인과 대기/blocked 학습 작업을 철회합니다. 실행 중 학습을 강제로 종료하지 않습니다. 검수 중 정책/데이터/모델/비용 설정이 바뀌면 결과를 승인으로 적용하지 않습니다. API 호출이 이미 시작된 경우 비용이나 외부 전송을 되돌릴 수는 없습니다.

같은 데이터 revision/정책 revision은 한 번만 심사합니다. 실패한 요청도 감사 기록을 남겨 반복 유료 호출을 막습니다. 다시 심사하려면 데이터를 다시 검수하거나 정책을 명시적으로 갱신해야 합니다. 타임아웃/중단으로 pending이 남아도 자동 재시도하지 않습니다. 사용량이 불명확하면 기존 예약 비용을 유지합니다. 일일 예산은 다른 OpenAI 호출과 함께 집계합니다.

감사 기록에는 데이터 ID·정책 revision·모델·검수 범위·샘플 수·이유·위험·비용 상태를 기록합니다. API 키는 노출하지 않습니다. 모델/키/단가/예산이 변경되면 기존 정책 바인딩은 사용할 수 없으며 다시 설정해야 합니다. 실제 모델 가중치 변경도 검수 전후 확인합니다.

Worker는 이제 BillingLedger를 사용해 opt-in 정책이 켜진 경우에만 GPT 승인 경로를 호출합니다. 모드가 꺼져 있으면 기존 무료 로컬 수집/검수 흐름을 유지합니다. 추가 환경변수는 없고 기존 OpenAI/학습 설정을 사용합니다.

자동 테스트는 Mock OpenAI를 이용하며 실제 유료 호출·GPU 학습·브라우저 E2E는 미검증입니다. 공식 기준: [OpenAI Text generation / Responses](https://developers.openai.com/api/docs/guides/text).

기존 3개 미리보기만 로컬 검수한 데이터는 Teacher/Reviewer의 전체 샘플 검수를 다시 완료해야 자동 승인을 받을 수 있습니다.
