# 무료 로컬 문서 검색

문서 관리 화면에서 UTF-8 `.txt`/`.md`를 업로드하고 검색하거나 원문을 내려받고 삭제할 수 있습니다. 계정별 최대 32개, 문서별 16,000자, 브라우저 원본 파일 최대 48KiB입니다. 전체 JSON 요청은 기존 64KiB 제한을 따릅니다. 같은 사용자/프로젝트/정규화 내용은 중복 보관하지 않습니다. 경로와 바이너리 제어문자를 거절합니다. 원문과 800자/100자 중첩 발췌는 SQLite에 저장하며 서버 경로 이름으로 쓰지 않습니다.

대화에 참고할 문서를 최대 5개 명시적으로 선택하고 프로젝트를 맞춥니다. 공통 문서는 어떤 프로젝트에서도 참조할 수 있습니다. 사용자 소유권 및 프로젝트 범위를 서버에서 검증합니다. 키워드 포함 점수 기준 상위 5개 발췌, JSON 문맥 4,500자 제한입니다. PDF 및 로컬 벡터/의미 검색은 별도 확장 안내를 참고하세요. DOCX와 형태소 검색은 후속 단계입니다. 일치가 없으면 빈 근거로 반환하며 근거를 만들어내지 않습니다.

새 문서 대화 기능은 Ollama/Mock만 지원하며 OpenAI·OpenClaw·vLLM에 문서를 보내지 않습니다. 유료 API, 원격 임베딩, 자동 모델 다운로드가 없습니다. 문서 명령은 신뢰하지 않는 참고자료로 구분하고 도구 권한을 부여하지 않습니다. 이는 모델의 프롬프트 인젝션 완전 방어를 보장하지 않습니다. 기존 도구 실행 차단 정책을 유지합니다.

채팅 응답에 원문 발췌와 문서/발췌 ID를 반환합니다. 대화와 함께 출처 식별자/파일명/위치를 원자적으로 보관하고 기록 재조회 시 표시합니다. 검색된 출처는 모델이 실제 활용했다는 검증이나 답변 정확성 보증이 아닙니다. 원문 삭제 시 발췌도 삭제하지만 기존 대화 및 출처 메타데이터는 남습니다. 문서는 기억·학습 데이터에 자동 편입되지 않습니다.

추가 환경변수/추가 외부 라이브러리는 없습니다. 기존 SQLite에 새 테이블을 추가하며 기존 데이터 컬럼을 변경하지 않습니다. 기능 롤백 시 이전 버전은 새 테이블을 무시합니다. 자동 테스트는 실제 API/GPU 없이 실행하며 실제 Ollama 응답 품질 및 브라우저 사용성은 실환경 검증 대기입니다.

PDF·로컬 의미 검색 확장은 [별도 안내](pdf-semantic-rag.md)를 참고하세요. 위 설명은 기본 키워드/text 경로이며 확장 기능의 제한과 설정은 해당 안내가 우선합니다.
