## 구현 경계

- 기존 사용자·문서·기억·메시지·대화 테이블의 열과 본문을 변경하지 않는다.
- v4는 `scope_projects`, `scope_policies`, `scoped_resources`, `scope_resource_versions`,
  `scope_read_grants`, `scope_memory_provenance`만 추가한다. 무결성 트리거도 새 테이블에만 설치한다.
- 프로젝트는 사용자별 불투명 ID와 기존 이름의 정확한 매핑으로 구분한다. Unicode·대소문자·공백을 임의 병합하지 않는다.
- 프로젝트 미지정 문서·출처 없는 기억은 개인 보관함에 비공개 분류한다. Grant는 만들지 않는다.
- 기존 대화는 범위 미확정 기록으로 보존한다. 대화 제목·본문에서 프로젝트를 추측하지 않는다.
- 원문 메시지에서 파생된 기존 기억은 출처 범위 확인 전 검토 필요 상태다. 기존 출처 ID와 본문은 보존한다.
- 버전은 문서 본문 digest 또는 기억 revision과 내용/출처 fingerprint로 결합한다. 과거 버전 본문을 별도 복제·서비스하지 않는다.
- Grant는 정확한 버전과 같은 사용자 소유의 지정 프로젝트에 대한 읽기 참조다. 수정·재공유 권한을 부여하지 않는다.
- 철회된 Grant와 버전·파생 출처는 삭제하지 않는다. 새 Grant가 생겨도 과거 철회 Grant에 의존한 기억은 살아나지 않는다.
- 기억 revision 변경에도 출처 의존성을 보존한다. 누락·충돌·순환·과도한 깊이는 사용 적격성 검사에서 거부한다.
- `ScopeRepository.can_read_version`은 미래 정책 연결을 위한 내부 검증 기반이다. 호출자의 인증을 대신하지 않는다.
- 기존 검색·대화·견적·OpenClaw API에는 연결하지 않는다. 따라서 실제 API의 프로젝트 격리가 완료됐다고 볼 수 없다.
- 원본에 연결된 범위/버전/출처는 FK RESTRICT로 삭제 보호된다. 후속 API의 삭제·보존 처리 연결이 필요하다.
- P1-01 계약 파일·기존 digest·Coding 실행 예산은 변경하지 않는다. PR #31 코드를 통합하지 않는다.

## 이행·복구 경계

기존 Migration의 명시적 트랜잭션·검증·오프라인 승인 흐름과 Backup의 무결성 검사·새 경로 복원을 재사용한다.
버전이 기록된 구 DB는 새 테이블이 미리 있어도 기본 기동에서 자동 backfill하지 않는다.
버전 기록이 없고 모든 테이블이 있는 DB도 문서·기억·대화가 하나라도 있으면 명시적 이행을 요구한다. 빈 새 DB 초기화와 자료가 없는 기존 import 호환은 유지한다.
새 테이블·CHECK·인덱스 조건·트리거를 검증한 뒤 같은 트랜잭션에서 분류하고 v4를 기록한다.
분류 후 실패를 주입하면 DDL·분류 행·버전 기록을 함께 rollback한다. 기존 본문은 보존한다.
현재 v4에서 무결성 구조가 누락·변조되면 자동 보수하지 않고 중단한다.

`prepare_scope_copy`는 명시적인 offline 확인과 새로운 목적지가 필요하며 CLI/HTTP에 연결하지 않는다.
기존 Backup으로 원본 DB+artifact를 백업하고 새 경로에 복원한 **복제 DB만** 업그레이드한다.
원본 백업은 그대로 유지하며 후보 DB는 `not_activated` 상태다. 실패한 후보와 원본 백업을 보존한다.
이 함수는 Coding checkpoint·비밀키·외부 모델·Docker volume의 전체 복구를 제공하지 않는다.

롤백은 다음 범위만 검증했다.

1. 합성 v3 이행 중 실패: 원본 행과 v3 버전 유지, 새 테이블·트리거·분류 rollback.
2. 복제본 준비 실패: 원본 DB와 검증된 source-backup 보존. 실패 목적지를 재사용하지 않는다.
3. 백업 복구: 기존 복원 함수로 **새 경로**에 복원하고 무결성·행 일치를 확인한다. 서비스 전환은 하지 않는다.

구버전 reader로 돌아가 자동 공통 검색을 재활성화하거나 운영 DB를 덮어쓰는 절차는 제공하지 않는다.
가동 중단·전환·전환 후 신규 쓰기 보존·과거 백업의 공유 철회 이력 대조는 DEC-015 후속 설계/승인 대상이다.
