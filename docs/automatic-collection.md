# AI 자동 학습 데이터 수집

소유자가 학습 데이터 화면에서 주제·간격·횟수를 등록하면 별도 수집 Worker가 일정을 실행합니다. 필요한 설정은 ROLE_AI_HF_DOWNLOAD_ENABLED=true 및 로컬 Ollama입니다. 네트워크 조회는 기본적으로 비활성화돼 있습니다.

Worker 실행:

- python -m role_ai.collection: 계속 실행하며 60초마다 예약 확인
- python -m role_ai.collection --once: 한 번 확인 후 종료
- docker compose --profile collection up -d --build: 웹 서비스와 수집 Worker 함께 실행

웹 API만 실행하면 자동 수집은 진행되지 않습니다. UI는 저장된 작업 상태를 보여주며 Worker가 연결됐다고 추정하지 않습니다. 현재 수집 Worker는 WSL2/Linux를 대상으로 합니다.

## 자동 실행 절차

1. 주제로 Hugging Face 검색
2. Ollama가 실제 검색 결과 안에서 데이터셋 선택
3. 고정 revision·라이선스 메타데이터·JSONL 파일 확인
4. Ollama가 파일을 선택하고 앞 1행에서 발견한 실제 문자열 필드를 질문/정답으로 매핑
5. 파일 앞 30행을 제한된 스트리밍으로 가져오기
6. 기존 중복 제거·일부 개인정보/비밀키 패턴 필터 적용
7. 압축 JSONL·데이터 카드·출처·해시 저장
8. 로컬 Teacher·Reviewer·오케스트레이터 순차 검수
9. 사용자 최종 검토 대기

세 검수는 하나의 공유 Ollama 모델을 역할별 프롬프트로 호출합니다. 원격·Cloud 모델, 유료 API, 데이터셋 스크립트 실행, 자동 모델 다운로드는 사용하지 않습니다. 다운로드는 기존 Hugging Face 공식 호스트·리다이렉트·토큰 제한을 따릅니다. AI 선택은 라이선스 이용 권한이나 데이터 품질을 보장하지 않습니다.

## 수집 범위와 한도

- 계정당 수집 계획: 5개
- 주기: 1~168시간, 기본 24시간
- 계획당 시도: 최대 30회, 기본 3회
- 실행당 데이터셋: 1개, 최대 앞 30행
- 후보 검색: 최대 10개, 파일 후보 최대 20개
- 메타데이터 응답: 각각 최대 256KiB
- JSONL 스캔: 기본 2MiB씩. 필드 확인과 실제 샘플 수집을 별도로 하므로 실행당 최대 4MiB에 메타데이터 전송이 추가됨
- 전체 학습 파일 저장 한도: 기존 기본 100MiB

실패해도 시도 횟수가 소모되고 다음 예약까지 기다립니다. 기존 사용자/revision/파일을 다시 발견하면 가져오기를 건너뜁니다. 사용자가 해당 데이터셋을 삭제하면 다시 수집될 수 있습니다.

## 사용자 승인과 검증 범위

앞부분 선별이므로 대표성 있는 무작위 표본이 아닙니다. 현재 JSONL만 지원하며 Parquet/CSV는 지원하지 않습니다. 파일·필드 선택이 틀리거나 정제 후 최소 10개 샘플이 남지 않으면 실패합니다. 개인정보 필터는 제한된 패턴 검사이므로 전체 샘플을 확인해야 합니다.

Teacher·Reviewer는 선택된 학습·평가 샘플 전체를 행별로 검수합니다. 로컬 오케스트레이터는 학습 미리보기 3개를 검수합니다. 같은 모델의 반복 검수는 독립적인 품질 보장이 아닙니다. 자동 검수가 통과해도 학습 계획·승인 해시·학습 작업을 만들지 않습니다. 사용자가 전체 샘플, 데이터/모델 라이선스, 개인정보를 확인하고 최종 승인한 후 기존 학습 작업 등록이 가능합니다. 자동 수집 데이터의 오케스트레이터는 로컬이므로 GPT 결제가 필수가 아닙니다. 기존 수동 GPT 검수는 별도 명시적 동의 경로로 유지합니다.

## 중지·복구

OS 잠금으로 여러 수집 Worker의 중복 실행을 막습니다. 중단된 running 작업은 잠금을 확보한 다음 실행에서 실패 이력을 남기고 다음 예약으로 복구합니다. 예약 중지는 다음 실행을 멈추며 이미 진행 중인 주기는 완료될 수 있습니다. 진행 중 계획 삭제는 거절합니다. 계획 삭제와 데이터셋 삭제는 별개입니다.

자동 테스트는 Mock HF/로컬 HTTP와 실제 정제·저장소·DB·일정 처리를 검증합니다. 실제 HF/Ollama 연결, 장시간 예약 운영, GPU는 실환경 검증 대기입니다. 소규모 개인용 기능이며 대량 크롤링 시스템은 아닙니다.

공식 기준: [Hugging Face Hub API](https://huggingface.co/docs/hub/api).
