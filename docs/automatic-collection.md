# AI 자동 학습 데이터 수집

소유자가 학습 데이터 화면에서 주제·간격·횟수를 등록하면 별도 수집 Worker가 일정을 실행합니다. `ROLE_AI_HF_DOWNLOAD_ENABLED=true` 및 로컬 Ollama가 필요합니다. 기본 네트워크는 비활성화입니다. Worker는 `python -m role_ai.collection`(계속 실행), `--once`(한번 확인) 또는 `docker compose --profile collection up -d --build`로 실행합니다. 웹 API만 켜놓으면 수집되지 않으며 UI는 Worker 상태를 추정해 실행 중으로 가장하지 않습니다.

계정당 계획5개, 간격1~168시간(기본24), 계획당최대30회(기본3), 실행당 데이터셋1개·앞30행, JSONL스캔기본2MiB입니다. 메타데이터는각256KiB, 후보검색10개, 파일후보20개. 실제 문자열 필드는 앞1행에서 발견합니다. 이 schema 확인과 실제30행 가져오기는 각각 제한된 스트리밍이므로 최대스캔량은 실행당4MiB에 메타데이터가 추가됩니다. 실패시에도횟수가소모되고 다음예약까지기다립니다. 총저장한도는 기존100MiB입니다.

순서: HF검색 → Ollama가 실제후보선택 → revision/라이선스메타데이터/JSONL파일확인 → Ollama가 파일/실제필드선택 → 앞30행가져오기 → 기존중복/개인정보패턴정제 → 압축JSONL/데이터카드/해시저장 → 로컬Teacher/Reviewer/오케스트레이터 순차검수 → 사용자 최종검토대기. 세검수는 같은 공유Ollama모델을 역할별프롬프트로 호출합니다. 원격·Cloud 모델/유료API/데이터셋스크립트실행/자동모델다운로드를 허용하지 않습니다. HF다운로드는 기존공식호스트와리다이렉트/토큰제한을따릅니다. AI추천은 라이선스사용권이나품질보장이 아닙니다.

중요한 한계: 앞부분선별이므로 대표성있는 랜덤표본이 아닙니다. 후보이름/파일/필드가부적합하거나10개이상정제샘플을확보하지못하면실패기록만남습니다. JSONL 이외의 Parquet/CSV는 현재미지원입니다. 검수는 현재 기존설계대로 학습샘플3개씩만대상이며 전체검수가 아닙니다. 자동검수가통과해도 approval_hash/학습계획/TrainingJob을 만들지 않습니다. 사용자가전체샘플·데이터/모델라이선스·개인정보를확인하고최종승인해야기존학습작업등록이가능합니다. 자동수집분의오케스트레이터는로컬이므로 GPT결제는필수가아닙니다. 기존수동GPT검수는별도명시적동의경로로유지합니다.

수집OS잠금으로여러Worker가중복실행하지않습니다. 수집이중단되면잠금을확보한다음재시작시기록복구및다음예약설정합니다. 일정중지는 다음예약을멈추며 이미실행중인주기는완료될수있습니다. 계획삭제는진행중에는거절하며기존데이터셋은별도로남습니다. 이미저장한사용자/revision/파일은다시가져오지않습니다. 데이터셋을사용자가삭제하면이력검사가사라져다시수집될수있습니다. 소규모개인용범위이며대량크롤링이아닙니다.

자동테스트는Mock HF/로컬HTTP와 실제정제/저장/DB/일정처리를검증합니다. 실제HF/Ollama호출·장시간스케줄/GPU는 실환경검증대기입니다. 공식기준: https://huggingface.co/docs/hub/api
