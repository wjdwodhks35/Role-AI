# 개발 로드맵

2026-10-27 사용자 결정: **개발자 모드 AI의 실제 작업 능력 완성을 1순위로 한다.**
기존 Phase 번호는 구성요소를 가리키며 더 이상 모든 Phase를 번호순으로 끝내는 것을 개발자 모드의 선행 조건으로 삼지 않는다.

## 1순위 — 대화하며 자기 개발 코드를 수정하는 AI

사용자가 Role-AI에 지시하면 개발자 모드 AI가 대화로 작업을 진행하고, 필요한 외부 사이트·문서를 읽고,
자신의 허용된 개발 저장소에서 코드를 수정·테스트하고 GitHub PR을 처리한다.
검사·충돌·검토 확인 후 dev에 병합하는 기존 개발 흐름을 연결한다. 운영 반영은 별도 승인이다.

상세 기능·권한·완료 기준: [개발자 모드 최우선 명세](architecture/DEVELOPER_AGENT_PRIORITY.md).

| 순서 | 개발 작업 | 상태 |
|---|---|---|
| 기반 | Phase 0/1 역할 정의·구성 조회·소스 기준선 | PR #25 dev 병합; 실제 Agent 실행/전체 성능 실측은 미완료 |
| D0 | 개발 대상·권한·실제 모델 기준선·평가 과제 확정 | 다음 작업 |
| D1 | 소유자 전용 개발 대화·작업 상태·중단 | 설계/구현 예정 |
| D2 | 외부 문서 읽기·근거 URL 반환 | 설계/구현 예정 |
| D3 | 독립 worktree 파일 탐색·코드 수정·diff | 설계/구현 예정 |
| D4 | 격리 테스트·린트·실패 분석·제한된 복구 | 기존 기반 재사용, 실행 루프 연결 예정 |
| D5 | 작업별 branch/commit/PR·CI·dev 병합 | 현재 Codex 개발 흐름은 사용 중; Role-AI 자체 도구 연결은 예정 |
| D6 | 실제 Role-AI 지시→웹 조사→수정→검증→PR E2E·성능 검증 | 미완료 |

새 역할 정의나 “실행했다”는 답변만으로 개발자 AI가 완성되었다고 판정하지 않는다.
Codex가 대신 수행한 PR과 Role-AI의 실제 로컬 모델/도구가 수행한 작업도 구분한다.

## 2순위 — 개발자 모드의 정확도·속도·복구 능력 보완

- 실제 작업 성공률과 반복 실패를 기준으로 도구 선택·문맥·추론 예산을 개선한다.
- 파일 경로·오류·diff·검증 결과를 보존하는 작업 기억과 필요한 검색만 추가한다.
- 모델 동시 로드·LLM 중복 호출을 줄이고 대화 지연/토큰/자원·전체 완료 시간을 측정한다.
- 모델/추론 설정 변경은 현행 기준선과 비교하고 필요한 별도 승인을 거친다.

## 3순위 이후 — 지속 학습 아키텍처 확장

1. 외부 소스 수집·Raw/manifest·정규화·중복/보안·라이선스 점검과 격리.
2. 일반 개인화 기억·Hybrid RAG·reranker·문서/소스 버전 관리.
3. Conversation/Research/Knowledge/Learning/Evaluation을 포함한 전체 역할 오케스트레이션과 중앙 큐 확장.
4. 검증된 에피소드의 SFT/DPO 후보화·독립 평가·승인된 격리 학습/후보 검증.
5. 전체 에이전트·수집 품질·실험·승인/복구·반응형 운영 UI.

D0~D6에 필요한 최소 작업 UI·웹 읽기·코딩 실행 경계는 이 후속 기능들을 기다리지 않고 먼저 만든다.
학습 데이터 수집이나 가중치 훈련이 개발자 모드의 코딩 능력 확보보다 앞서지 않도록 한다.

## 계속 유지하는 조건

- 기존 대화·Study-AI·기억/문서·인증·세션·CSRF·DB·원본 사용자 파일과 미커밋 작업을 보존한다.
- 대화 OpenClaw 도구 전체 차단과 PC 실행 승인 경계를 유지한다. 개발 작업은 별도 격리 경계에서 실행한다.
- 최신 dev의 독립 feature/fix 브랜치 → PR(dev) → 테스트·CI·검토 확인 → dev 병합을 따른다. main 직접 반영은 하지 않는다.
- 모델 설치/교체·실제 학습·운영 배포·DB/환경변수/Gateway·보안/권한 변경은 별도 승인한다.
- 실측/추정, 실제/모의, 개발 코드/운영 적용을 구분한다. 테스트 통과만으로 운영 배포나 모델 성능 향상을 주장하지 않는다.

기존 구현 범위와 검증 이력은 [Phase 0/1 기반 문서](architecture/CONTINUAL_LEARNING_FOUNDATION.md),
각 기능 안내 및 Git 이력에 남아 있다. 이 로드맵 변경 자체는 실행 기능을 활성화하지 않는다.
