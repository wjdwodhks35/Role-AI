Role-AI 실행 방법

1. 이 폴더의 Start-RoleAI.cmd를 더블클릭하세요.
2. 서비스가 준비되면 http://127.0.0.1:8000 이 열립니다.
3. PC Gateway용 최소화된 WSL 창은 닫지 마세요.
4. 메인 창에 오류 또는 경고가 나오면 해당 내용을 확인하세요.

Companion 연결 경고가 나오면 OpenClaw Companion에서
기존 Gateway ws://127.0.0.1:18790 연결과 Node mode를 확인하세요.
토큰이나 승인 정책을 초기화할 필요는 없습니다.

Windows 로그인 자동 실행은 등록하지 않았습니다.
AI가 계산기 등 프로그램을 실행하는 기능은 별도 검증이 필요합니다.
