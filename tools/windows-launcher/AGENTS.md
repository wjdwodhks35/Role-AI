# Windows 실행 도우미 규칙

- 기존 이미지·설정을 사용한다. 임의 빌드/pull·Ollama 주소 변경·포트 점유 프로세스 종료·불필요한 컨테이너 재생성을 피한다. 오래된 API 네트워크 참조가 확인된 OpenClaw만 복구한다.
- PC Gateway는 serveradmin으로 실행하며 중복 실행을 방지한다. 실패 원인과 재시도 방법을 표시한다. Companion 시작 요청과 실제 노드 연결을 구분한다.
- `.ps1`은 UTF-8 BOM/CRLF, `.cmd`는 CRLF, Linux 스크립트는 LF를 유지한다.
- PowerShell 구문 검사와 Windows 실제 실행을 구분한다. 재부팅하지 않았다면 재부팅 검증을 주장하지 않는다. 창만 변경할 때 서비스를 불필요하게 재시작하지 않는다.
- Gateway 최소화 창 유지, 전용 창 로그인 프로필, 자동 실행 미등록 등 사용자 동작에 영향을 주는 사항은 README와 실행방법.txt에 반영한다.
