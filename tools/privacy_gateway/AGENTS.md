# 로컬 보안 게이트웨이 개발 규칙

- 기본 외부 연결 차단과 요청별 검토·일회 승인을 유지한다. 최종 조립 문맥을 검사하고 미리보기와 다른 원문을 전송하지 않는다.
- 실제 키·원문·토큰·대응표를 로그/소스/테스트 결과에 남기지 않는다. 테스트는 가짜 값과 loopback 모의 서버만 사용한다.
- 전역 프록시·방화벽·Codex 연결·제공자 결제·기존 앱을 임의로 변경하지 않는다. 리다이렉션·자동 폴백·도구 실행을 추가하려면 별도 검토한다.
- 가명화는 완전한 익명화가 아니며 store=false는 제공자 보존 금지를 보장하지 않는다. 검사 한계와 현재 미적용 경로를 문서에 명시한다.
- 런타임은 WSL/Linux다. 비밀 파일 권한을 보장하지 못하는 플랫폼에서 조용히 실행하지 않는다.
- 관련 검사는 `python3 -m unittest discover -s tools/privacy_gateway/tests -v`다. 운영 DB·서버·실제 외부 모델은 검증에 사용하지 않는다.
