# 로컬 보안 검토 게이트웨이

Windows 바탕 화면 `RoleAI-Privacy/Start-PrivacyGateway.cmd`를 더블클릭한다. WSL Ubuntu의 serveradmin 계정으로 로컬 서비스와 화면을 연다. 최소화된 WSL 창은 유지한다. 새 의존성·모델·외부 제공자는 설치하지 않았다. 동작 환경은 Python 3.11+가 있는 WSL/Linux다.

1. 보낼 질문·코드 일부만 입력하고 **로컬 검사·가림**을 누른다.
2. 로컬 작업 기록을 포함한 요청 전체와 전송 대상을 확인한다. 처음에는 외부 연결이 꺼져 있어 전송할 수 없다.
3. 진행 상황·결정·다음 작업은 **로컬 작업 기록**에 적고 저장한다. 가려진 요약이 `WORK_NOTES.md`로 남아 재시작 후에도 로드된다.
4. 별도로 외부 제공자를 설정한 경우에만 체크박스로 검토를 승인하고 요청 1회를 보낸다. 실패한 요청도 승인을 재사용하거나 다른 모델로 자동 재시도하지 않는다.

## 저장 위치

`/home/serveradmin/Role-AI/.codex-local/privacy-gateway/`

- `policy.json`: 민감한 고유명칭 목록과 단일 업스트림 설정
- `WORK_NOTES.md`: 가려진 작업 요약. 외부 요청 시 항상 미리보기에 포함
- `access-token`: 로컬 화면/API 인증값. 외부 모델이나 다른 프로그램에 공유하지 않음
- `mask-key`: 가명 생성용 로컬 HMAC 키. 대응 원문 목록은 저장하지 않음

이 폴더는 Git에서 제외된다. WSL에서 디렉터리 0700, 파일 0600을 사용한다. 이는 다른 OS 사용자에 대한 보호이며 같은 사용자 권한의 Codex·다른 프로그램까지 격리하지 않는다. 비어 있지 않은 임의 폴더나 직접 연결된 심볼릭 링크를 상태 폴더로 사용하는 것은 거부한다.

이름·회사명 등은 자동 인식이 보장되지 않으므로 `policy.json`의 `private_terms`에 직접 등록한다. 예: `"private_terms": ["가릴 실제 이름", "가릴 실제 회사명"]`. 형식은 JSON 문자열 배열이며 원본을 외부로 전송하지 않는다. 비밀값 자체를 작업 요약에 적지 않는다.

## 검사와 전송 정책

- 알려진 키·비밀번호·Bearer/JWT·개인키·긴 불투명 문자열은 요청 전송과 기록 저장을 차단한다.
- 이메일·한국 휴대전화·주민번호 형태·개인 경로·등록 민감어는 일관된 가명으로 치환한다. 자동 탐지는 휴리스틱이며 모든 개인정보·계좌번호·사업 기밀을 식별하지 못한다.
- 가림은 로컬에서 수행한다. 원문 질문을 디스크 로그에 보관하거나 원문→가명 대응표를 저장하지 않는다. 질문·미리보기·전송 승인 초안은 브라우저/프로세스 메모리에 존재하며 초안은 최대 50개, 10분간 유지된다.
- 브라우저 인증값은 URL fragment로만 전달하고 페이지 로드 후 주소에서 제거한다. HTTP query·요청 로그·로컬 저장소에 보관하지 않는다. 신뢰할 수 있는 브라우저·확장 환경이 필요하다.
- 승인 초안에는 당시의 가려진 기록과 질문만 고정된다. 정책이 바뀌면 재검토해야 한다. 전송 직전 최종 문맥을 다시 검사한다.
- 임의 요청 헤더·이미지·파일 첨부·도구 호출·이전 서버 대화 ID는 외부로 전달하지 않는다. 응답의 구조화된 도구 호출도 거부한다. 텍스트 JSON을 실행하지 않는다.
- localhost 전용 바인딩, 로컬 Bearer 인증, Host/Origin 확인, 요청/응답 용량 상한을 적용한다. 환경변수 HTTP 프록시와 HTTP 리다이렉션을 사용하지 않는다.
- 이 프로그램은 임의 파일 경로를 받아 내용을 읽거나 셸 명령을 실행하는 API를 제공하지 않는다. PC 전체의 파일 접근 권한이나 방화벽을 변경하지는 않는다.

## 외부 연결은 기본 꺼짐

현재는 `upstream.enabled=false`이며 실제 외부 API 키를 등록하지 않았다. 외부 연결을 사용하려면 소유자가 `policy.json`에 `enabled`, 명시적 전체 URL, 고정 model을 설정하고 서비스 실행 환경에 별도 `PRIVACY_UPSTREAM_KEY`를 제공해야 한다. 키를 웹 화면이나 작업 기록에 입력하지 않는다. HTTPS 또는 숫자 loopback HTTP 주소만 허용한다.

지원 범위는 비스트리밍 OpenAI Chat Completions 형태의 텍스트 요청·응답이다. Codex Responses 프로토콜·스트리밍·일반 API 투명 프록시는 구현하지 않았다. 실제 제공자 연결은 검증하지 않았다. FreeLLMAPI에 연결하더라도 그 내부 폴백/제공자 선택까지 이 게이트웨이가 통제하는 것은 아니다.

`store=false`를 요청하더라도 제공자의 로그·보존·학습 미사용을 강제할 수 없다. 외부에서 처리한 내용은 외부 제공자에게 전달된다. 민감도 판단이 불확실하면 보내지 않는다.

## 보장하지 않는 범위

- 현재 Codex 채팅·기존 Role-AI의 네트워크 요청은 자동으로 이 프로그램을 거치지 않는다. 기존 Codex의 입력·파일·도구 결과가 보호된 상태라고 가정하면 안 된다.
- 같은 OS 계정의 프로그램은 로컬 인증값을 읽을 수 있다. 인증값을 가진 클라이언트는 API로 승인을 제출할 수 있어 이 화면의 체크박스는 강제적인 사람 확인 수단이 아니다. 신뢰할 수 없는 에이전트에 인증값을 주지 않는다.
- 완전한 DLP·악성코드 차단·익명성·모든 기밀 탐지·외부 보존 금지를 보장하지 않는다. 전송 금지 원본의 별도 OS 계정/컨테이너 격리는 후속 작업이다.
- 서버를 종료해도 저장한 작업 요약은 남지만, 원문 질문·외부 응답은 자동 저장하지 않는다. 남길 내용만 작업 기록에 직접 저장한다. 자동 가명 복원은 하지 않는다.

## 검증

표준 라이브러리만 사용한다. `python3 -m unittest discover -s tools/privacy_gateway/tests -v`로 검사한다. 개인정보 치환·비밀 차단·기본 네트워크 미사용·명시적 일회 승인·정책 변경·재시작 기록·권한·로컬 모의 업스트림·인증·Host/Origin·리다이렉션·도구 호출 거부를 검증했다. 모의 업스트림은 127.0.0.1만 사용하며 실제 외부 모델 호출은 없다.
