GPU 메모리 설정

GPU 0 한 개에 적용합니다. GPU 전체 사용량과 예상 추가 메모리를 기준으로 새 작업 시작을 제한합니다. 다른 프로그램을 강제로 종료하거나 GPU를 분할하지 않습니다.

작업별 예상 추가 메모리

모델과 작업에 따라 달라지는 추정값입니다. 실제 GPU에서 확인 후 조정하세요. 이미 로드된 모델은 보수적으로 추가 계산되므로 작업이 대기할 수 있습니다.

변경은 다음 작업부터 적용됩니다. 검사 활성화 시 측정할 수 없으면 작업을 시작하지 않습니다. 채팅은 한도 초과 안내 후 다시 시도하며, 학습은 대기 상태로 남습니다. 학습 할당기 제한 외의 GPU 사용량은 강제 상한을 보장하지 않습니다.

문서와 검색 근거

UTF-8 텍스트·Markdown 최대 48KB, PDF 최대 512KB·20페이지. 추출 텍스트는 최대 16,000자, 계정당 32개. PDF 원본은 보관하지 않으며 스캔 PDF OCR은 미지원. 문서는 학습·장기 기억에 자동으로 저장되지 않습니다. 키워드 또는 설정된 로컬 모델의 의미 검색을 선택할 수 있습니다.


    
대화에 사용할 문서를 최대 5개 선택하세요.채팅의 프로젝트와 문서의 프로젝트를 맞춰주세요.
      문서 대화는 Ollama 또는 Mock만 지원합니다. 검색 근거는 모델 답변의 정확성을 보장하지 않습니다.
